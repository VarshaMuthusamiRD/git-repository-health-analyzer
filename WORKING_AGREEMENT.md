# Working Agreement

## Pull Request Size

Keep pull requests focused on one task or closely related small tasks.

## Review Time

Review pull requests as soon as possible and avoid leaving work blocked.

## Definition of Done

A task is done when:

- The implementation matches the task.
- Tests pass.
- The code does not modify unrelated functionality.
- The relevant documentation is updated.

## Stuck Rule

If no progress is made for 20 minutes, stop and investigate the blocker
or seek help instead of continuing blindly.

## Late Handoff

If a dependency is late, record the blocker and work on the next
unblocked task without expanding scope.

## Main Branch

Never push directly to `main`.

All changes go through a pull request.
